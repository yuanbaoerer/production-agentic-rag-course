# 第3周：关键词搜索优先 - 关键基础

> **🚨 90%的问题：** 大多数RAG系统直接跳到向量搜索，错过了驱动最佳检索系统的基础。我们要做对！

此文件夹包含arXiv论文管理器项目第3周的材料，我们使用OpenSearch和BM25评分实现专业RAG系统所依赖的**关键词搜索基础**。

## 🎯 为什么关键词搜索优先？

**专业路径：** 与直接跳到向量嵌入的教程不同，我们构建成功公司使用的基础：

1. **🔍 精确匹配能力：** 关键词擅长查找特定技术术语、论文ID和精确短语
2. **📊 可解释结果：** 你可以准确理解为什么检索到某篇论文
3. **⚡ 速度和效率：** BM25计算快速，不需要昂贵的嵌入模型
4. **📈 生产现实：** Elasticsearch、Algolia和企业搜索等公司将关键词搜索作为基础

**学习路径：**
```
第3周：掌握BM25关键词搜索    ← 你在这里
第4周：添加智能分块
第5周：引入向量嵌入实现混合检索
第6周：优化完整系统
```

## 实现的关键功能

### 🔍 **生产级搜索系统**
- **BM25评分**：行业标准相关性排名算法
- **多字段搜索**：跨标题（3倍加权）、摘要（2倍加权）和内容（1倍加权）查询
- **高级过滤**：类别过滤、日期范围和自定义字段查询
- **实时高亮**：结果中带有HTML标记的搜索词高亮
- **分页支持**：使用size/from参数高效处理大结果集
